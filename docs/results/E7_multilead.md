# E7. Режим MC (12 отведений → 12 поотведенческих выходов): без аугментаций и со всеми аугментациями

**Дата:** 2026-10-10. **Конфиги:** [mc_baseline.yaml](../../experiments/configs/mc_baseline.yaml), [mc_full.yaml](../../experiments/configs/mc_full.yaml) (настройки E6, [e6_select_e7.py](../../experiments/scripts/e6_select_e7.py)). **Прогоны:** `experiments/mc_baseline/fold*_seed{0,1}`, `experiments/mc_full/fold*_seed{2,3}` (`step.csv`, `metrics.json/md`, `thresholds.json`, `predictions_*.json`); окружение — `environment.json` (git `51481d4`, `git_dirty: false`, RTX 5060 Ti); логи — `experiments/logs/mc_*.log`. Анализ ошибок — [e7/](e7/) ([error_analysis.py](../../experiments/scripts/error_analysis.py)), картинки — [plot_s_vs_mc.py](../../experiments/scripts/plot_s_vs_mc.py).

**Итог.** Многоканальный вход **не улучшил делинеацию по метрике LUDB**: ⟨F1⟩₆ немного выше, чем у режима S (+0.16–0.18 п.п., в пределах шума δ_F1 = 0.37), а **⟨σ⟩₆ хуже на 3.2–3.3 мс во всех 10 парах из 10** (13.6 → 16.9 мс). Причина (E6 §4, подтверждено на всех фолдах): модель ставит **общую для отведений границу волны** вместо границы своего отведения. MC исправляет часть ошибок «P не видна в отдельном отведении» (полная блокада ножки: F1 P 77 → 87 %), но теряет P при ЭКС (Se P 6 %) и даёт больше ложных P при ФП. Аугментации в MC дают +0.17 п.п. F1 (как и в S) и не меняют σ. **Основным результатом статьи остаётся режим S (E4).**

## 1. Протокол
- Данные и модель — M6/M7: вход 12 × 5120 (Z-score по отведению, маска краёв по зоне каждого отведения), голова с 12 наборами предсказаний, лосс исходный по отведениям с суммой (`joint`), 24 непригодных отведения вне лосса и метрик. **Метрики — как в S:** те же 2376 тестовых отведений, 6 точек, ±150 мс, пороги по классам на val, граничные точки исключены.
- Обучение (E6): nano, страйды B, batch 8 записей (96 отведений), lr 0.01, EMA, выбор `best.pt` по val ⟨F1⟩₆. `mc_baseline` — 450 эпох, early stopping 120 (шаги как E2); `mc_full` — 750 эпох (шаги как E4), early stopping 120.
- Аугментации `mc_full` (A3): вероятности E4 для 15 сигнальных аугментаций в многоканальном варианте (A3-инверсия выключена) + L1 lead dropout (p 0.5, ignore), L2 shuffle (p 0.1), L3 перестановка электродов (p 0.2).
- **Парное сравнение по (фолд, сид):** `mc_baseline` (сиды 0, 1) ↔ E2 `baseline`, `mc_full` (сиды 2, 3) ↔ E4 `final`.

## 3. Почему границы хуже: консенсусная граница
[boundary_averaging.py](../../experiments/scripts/boundary_averaging.py), test всех 5 фолдов, seed 2 (только границы, где своя разметка отличается от медианы той же волны по отведениям записи ≥ 4 мс):

| Точка | S: ⟨|pred − своё|⟩ / ⟨|pred − медиана|⟩, мс | S: ближе к медиане | MC: ⟨|pred − своё|⟩ / ⟨|pred − медиана|⟩, мс | MC: ближе к медиане |
|---|---|---|---|---|
| P on | 9.1 / 13.0 | 39 % | 13.6 / 8.6 | **65 %** |
| P off | 8.0 / 13.6 | 35 % | 11.8 / 10.3 | **59 %** |
| QRS on | 6.6 / 6.4 | 50 % | 8.8 / 4.9 | **70 %** |
| QRS off | 7.2 / 7.6 | 46 % | 10.3 / 5.1 | **72 %** |
| T on | 13.1 / 21.1 | 34 % | 20.9 / 16.4 | **58 %** |
| T off | 11.7 / 16.3 | 38 % | 18.4 / 11.1 | **68 %** |

Из 12-канального входа сеть выучила одну «границу волны сердца» и выдаёт её во все отведения. Относительно медианы по отведениям MC точнее (QRS 4.9–5.1 мс), но разметка LUDB поотведенческая: границы одной волны между отведениями расходятся (медиана разброса QRS 24, P 50, T 88 мс, [R1](../research/R1_ludb.md)), и это расхождение ложится в σ. Это совпадает с литературой ([R5](../research/R5_multilead.md) §1: Moskalenko 2020 — усреднение 12 отведений улучшает детекцию и ухудшает границы; Jiménez-Pérez 2021 — multi-lead вход на малых данных хуже по σ). Ни настройки обучения (E6), ни аугментации (E7) этого не меняют.

## 4. Анализ ошибок по категориям (пулинг сидов; [e7/mc_full/by_category.md](e7/mc_full/by_category.md), S — [e4/by_category.md](e4/by_category.md))

| Категория | S `final`: ⟨F1⟩₆ / ⟨σ⟩₆ / F1 P | MC `mc_full`: ⟨F1⟩₆ / ⟨σ⟩₆ / F1 P | MC без аугм. |
|---|---|---|---|
| Без патологий (34) | 99.84 / 10.3 / 99.7 | **99.94** / 13.0 / 99.9 | 99.93 / 12.9 |
| Синусовый ритм (175) | 99.41 / 12.9 / 98.7 | **99.63** / 16.1 / 99.3 | 99.45 / 16.3 |
| AV-блокада I ст. (10) | 98.62 / 16.5 / 98.0 | **99.44** / 20.0 / 99.7 | 99.07 / 20.2 |
| Предсердная экстрасистолия (7) | 98.67 / 15.1 / 96.9 | **99.35** / 18.6 / 98.1 | 97.44 / 18.9 |
| **Полная блокада ножки (8)** | 92.26 / 15.1 / **77.4** | **95.40** / 21.4 / **86.7** | 97.78 / 21.4 |
| Ишемия / инфаркт (51) | 98.50 / 15.5 / 97.0 | 98.46 / 19.6 / 97.2 | 98.40 / 19.7 |
| ФП / трепетание (15) | 97.59 / 18.5 / — (ложных P 2.03 на отв.) | 98.05 / 24.0 / — (**2.33**) | 98.11 / 23.7 |
| Желудочковая экстрасистолия (7) | 95.49 / 14.1 / 89.3 | 92.86 / 20.2 / **81.3** | 96.65 / 21.0 |
| **ЭКС (10)** | 79.50 / 22.6 / 40.8 | **73.21** / 25.1 / **20.4** | 68.15 / 25.7 |

1. **Ошибка типа 1 из E4 (P не видна в отдельном отведении) уменьшилась.** Полная блокада ножки: F1 P 77.4 → 86.7 % (без аугментаций — ⟨F1⟩₆ 97.8 %); запись 116: ⟨F1⟩₆ 78.1 → 94.5 %, пропусков 218 → 78; запись 24: 92.5 → 99.5 %. Однако улучшение неравномерно: в 116 отведение II у MC (seed 2) теряет 5 P, которые S находит ([s_vs_mc_116.png](e7/s_vs_mc_116.png), [s_vs_mc_24.png](e7/s_vs_mc_24.png)).
2. **ЭКС: MC теряет P.** Se P при ЭКС (seed 2) 6 % против 73 % у S. В записи 72 (ЭКС с предсердной стимуляцией, P размечены) S находит почти все P, MC — почти ни одной ([s_vs_mc_72.png](e7/s_vs_mc_72.png)): по общему 12-канальному виду записи сеть, похоже, выучила правило «стимулированный ритм → P нет» (в большинстве записей с ЭКС P не размечены, AV-блокада III ст.). Желудочковая экстрасистолия — тоже хуже по P (89 → 81 %).
3. **ФП/трепетание:** ложных P больше (2.03 → 2.33 на отведение, 97 % стоят перед QRS); межотведенческий контекст не помогает отличить F-волну от P ([s_vs_mc_103.png](e7/s_vs_mc_103.png)). F1 T при ФП немного выше (95.5 → 96.1 %).
4. **Синусовый ритм и лёгкие патологии** — по F1 MC лучше (99.63 против 99.41 %, без патологий 99.94 %), но σ хуже на 2.7–3.5 мс во всех категориях.
5. По отведениям ([e7/mc_full/by_lead.md](e7/mc_full/by_lead.md)): ⟨F1⟩₆ выравнивается — диапазон 98.00–99.35 % у S сужается до 98.47–99.08 % у MC; «слабые» III, aVL, V1, V2 выигрывают 0.4–0.6 п.п., лучшее у S отведение II проигрывает 0.3 п.п.; σ хуже во всех 12 отведениях (+1.3…+4.9 мс).

## 5. Переобучение и недообучение
| Прогон | train ⟨F1⟩₆ | test ⟨F1⟩₆ | train ⟨σ⟩₆ | test ⟨σ⟩₆ |
|---|---|---|---|---|
| `mc_full` fold 0, seed 2 (лучшая эпоха 24) | 98.46 % | 98.87 % | 17.0 мс | 16.4 мс |
| `mc_full` fold 3, seed 2 (лучшая эпоха 30) | 99.74 % | 98.90 % | 12.4 мс | 16.3 мс |
| *S `final` fold 0 / 3, seed 2 (E4)* | *99.80 / 99.67 %* | *99.05 / 98.53 %* | *7.8 / 9.2 мс* | *14.2 / 12.8 мс* |

- **MC недообучен по границам**, а не переобучен: train σ 12.4–17.0 мс против 7.8–9.2 у S, разрыв train/test по σ мал (−0.6…+3.9 мс). У fold 0 test лучше train — чекпоинт взят на 24-й эпохе.
- **Ранний выбор чекпоинта:** лучшие эпохи `mc_full` — 24–208 (медиана ≈ 113), при остановке на 145–444; у `mc_baseline` — 31–147. Val (16 записей) у MC насыщается по F1 (99.9 % уже на 20–50-й эпохе, E6), и выбор по val ⟨F1⟩₆ становится случайным по σ. Для MC выбор по ⟨σ⟩₆ при насыщенном F1 или по val-лоссу мог бы дать чекпоинты точнее по границам — но это не устраняет консенсусную границу (train σ высок и в поздних эпохах, E6).
- Лимиты эпох достаточны: `mc_baseline` 152–275 из 450, `mc_full` 145–444 из 750 (ни один не дошёл до лимита).

## 6. Сравнение с литературой
Moskalenko 2020 (5c, усреднение выходов 12 отведений): ⟨F1⟩ 99.13 % по **общей** разметке; наш MC — 98.90 % по **поотведенческой** разметке, протоколы несравнимы напрямую. Качественно результат тот же: межотведенческий контекст улучшает обнаружение волн (Se) и ухудшает точность поотведенческих границ.

## 7. Выводы
1. **MyNet-1d работает с 12-канальным входом без изменения лосса** (детекция ⟨F1⟩₆ 98.9 %, на синусовом ритме 99.6 %) — архитектура многоканальна, как и в исходной вихретоковой задаче.
2. **Для поотведенческой метрики LUDB режим S лучше:** σ ниже на 3.3 мс при равном F1. Межотведенческий контекст полезен для детекции (P в отведениях, где она не видна) и вреден для поотведенческих границ (консенсусная граница) и для редких ритмов (ЭКС — P теряются).
3. Аугментации в MC дают тот же эффект, что в S (+0.17 п.п. F1), σ не меняют.
4. **Для статьи:** основная таблица — режим S (E4); MC — дополнительный эксперимент «многоканальный вход», с выводом о компромиссе детекция ↔ точность границ. Возможные продолжения (вне плана, по решению пользователя): гибрид (детекция MC + границы S), поотведенческие ветви головы, выбор чекпоинта MC по σ, оценка MC по общей разметке (как Moskalenko 5c / ECG-CODE).
