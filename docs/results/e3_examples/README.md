# Примеры работы сети на валидации (фолд 0): Full против baseline

Генерация: `python experiments/scripts/plot_predictions.py`. Модели — `best.pt` fold 0, seed 0: **Full** (`experiments/abl_full`, все 16 аугментаций) и **baseline** (`experiments/baseline`, без аугментаций); пороги уверенности по классам — с val каждой модели. Сигналы — val фолда 0 (16 записей, модели их не видели при обучении, по ним только выбирался чекпоинт и пороги).

Обозначения: P — зелёный, QRS — красный, T — синий; верхняя строка каждого отведения — разметка эксперта (ожидаемый ответ), ниже — ответы моделей. Штриховка с пурпурной рамкой — ложная детекция, пунктир — пропущенная волна эксперта, серый фон — эксперт не размечал (ложные там не считаются). В заголовках — упрощённое сопоставление волн (центр ≤ 150 мс) и средняя |ошибка| границ совпавших волн; метрики статьи считаются по 6 точкам (M1).
