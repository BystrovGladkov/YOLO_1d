Для E7 выбрана эталонная настройка **nano, batch 8 записей, lr 0.01, 450 эпох / early stopping 120** (шаги как в E2): все варианты равны по val ⟨F1⟩₆, ни один не лучше по σ больше чем на 0.3 мс. **Главная находка:** MC детектирует волны не хуже S, но **ставит границы хуже** (test ⟨σ⟩₆ 15.7 против 14.2 мс, val 18.5 против 14.0 мс) — модель выучила **общую для отведений («консенсусную») границу волны** вместо границы своего отведения (§4).

## 1. Условия
- Данные M6 (12 × 5120, маска краёв по отведениям, 24 непригодных отведения вне лосса), модель M7 (`n_leads 12`, лосс `joint`), без аугментаций (pipeline как у E2), fold 0, seed 0. Эталон S — E2 `baseline` fold 0 seed 0 (тот же фолд и сид).
- Пересчёт эпох по шагам оптимизатора: в S эпоха ≈ 1714 отведений / batch 32 = 54 шага, 150 эпох ≈ 8100 шагов; в MC эпоха — 144 записи, batch 8 → 18 шагов → **450 эпох**, early stopping 40 эпох S ≈ **120** эпох MC, warmup 3 → **9** эпох. Эффективный батч — 96 отведений (M7).
- Выбор настроек — по val ⟨F1⟩₆ лучшей эпохи; правило зафиксировано до просмотра итогов (`e6_select_e7.py`): ничья в пределах 0.1 п.п. → меньший val ⟨σ⟩₆, при разнице < 0.3 мс — эталон.

## 4. Почему σ хуже: «усреднение» границ между отведениями
Скрипт [boundary_averaging.py](../../experiments/scripts/boundary_averaging.py): для каждой совпавшей границы сравниваются ошибка относительно своего отведения и относительно медианы той же волны по отведениям записи (только границы, где своя отличается от медианы ≥ 4 мс).

| Точка | S: |pred − своё| / |pred − медиана|, мс | S: ближе к медиане | MC: |pred − своё| / |pred − медиана|, мс | MC: ближе к медиане |
|---|---|---|---|---|
| P on | 9.4 / 13.2 | 38 % | 12.6 / **8.2** | **66 %** |
| P off | 8.2 / 13.4 | 34 % | 11.2 / **10.3** | **56 %** |
| QRS on | 5.6 / 6.4 | 43 % | 7.7 / **4.7** | **65 %** |
| QRS off | 6.3 / 7.7 | 38 % | 9.5 / **5.8** | **66 %** |
| T on | 13.5 / 21.0 | 34 % | 19.8 / **16.4** | **56 %** |
| T off | 12.4 / 16.1 | 38 % | 16.8 / **10.2** | **67 %** |

- **S** ставит границу по своему отведению (ближе к своей разметке в 57–66 % случаев). **MC** — ближе к **медиане по 12 отведениям** (56–67 %): из общего 12-канального входа сеть выучила одну «границу волны сердца» и выдаёт её во все отведения, сглаживая поотведенческие различия разметки (медиана разброса границ по отведениям: QRS 24, P 50, T 88 мс, [R1](../research/R1_ludb.md)).
- Подтверждает риск, описанный в литературе ([R5](../research/R5_multilead.md) §1: Moskalenko 5c, Jiménez-Pérez 2021). Относительно медианы MC точнее, чем S относительно своей разметки (QRS on 4.7 против 5.6 мс) — т. е. MC хорошо находит «общую» границу, но метрика LUDB поотведенческая.
- Это не переобучение: train ⟨σ⟩₆ MC = 13.7 мс против 10.1 мс у S ([train_vs_test.py](../../experiments/scripts/train_vs_test.py): train 99.80 % / 13.7 мс, test 98.83 % / 15.7 мс; разрыв по σ 2 мс против 4.1 у S). Модель **недоучивает поотведенческие границы** даже на train; минимум val-лосса — эпоха 148, train-лосс 2.21 в конце (у S — 1.92 при 70 эпохах).

## 5. Решения для E7 и гипотезы
- E7 запущен с выбранной настройкой (коммит `51481d4`): `mc_baseline` — 5 фолдов × сиды 0, 1 (пары с E2), `mc_full` — все аугментации A3, 750 эпох (шаги как в E4), сиды 2, 3 (пары с E4). На всех фолдах проверить: сохраняется ли выигрыш по F1 (P в записях с невидимой P, ФП) и проигрыш по σ.
- Аугментации E7 (L1 lead dropout, перестановки отведений) скорее усилят межотведенческое усреднение; если σ в E7 останется хуже S, возможные меры (вне текущего плана, по решению пользователя): поотведенческие ветви головы (групповые свёртки по отведениям), вспомогательный вход «своего» отведения в голову, гибрид (детекция MC + уточнение границ S).
