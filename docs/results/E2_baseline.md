# E2. Выбор архитектуры, размера и гиперпараметров baseline (без аугментаций)

**Дата:** 2026-10-07. **Код:** коммит `9d7769e` (все прогоны — с чистой рабочей копией по отслеживаемым файлам). **GPU:** RTX 5060 Ti.
**Общее для всех прогонов:** вход 1 × 5120 (полная запись), маска краёв со случайным δ на train (D5), Z-score, без аугментаций, EMA 0.999 / τ 200, `bias_init: 1d`, выбор `best.pt` по val `F1_mean6` (фиксированный conf 0.25), итоговые метрики на test с порогами по классам, подобранными на val, граничные точки исключены. Лосс исходный.
**Протокол:** этапы 1–2 — фолды 0 и 1, seed 0, до 80 эпох, early stopping 20. Финал — 5 фолдов × 2 сида. Решения принимаются по **val** (`F1_mean6` — основная метрика, `sd_mean6` — вторичная; R2 §3.3); test в таблицах — для информации.
Конфиги: [experiments/configs/e2s1_*.yaml, e2s2_*.yaml](../../experiments/configs/) (генератор [make_e2_configs.py](../../experiments/scripts/make_e2_configs.py)), [baseline.yaml](../../experiments/configs/baseline.yaml). Сводки по прогонам: [e2/stage1_runs.txt](e2/stage1_runs.txt), [e2/stage2_runs.txt](e2/stage2_runs.txt) (скрипт [e2_collect.py](../../experiments/scripts/e2_collect.py)).

(среднее по фолдам 0–1; val F1₆ — лучшая эпоха при conf 0.25)

- **Победитель — B nano**: +0.4…0.85 п.п. val F1₆ к остальным (больше порога δ_F1 = 0.2 п.п.) при σ хуже A на 0.35 мс (меньше δ_σ = 0.5 мс). Выигрыш даёт в основном **P** (+1 п.п. F1). Видимо, на уровне со страйдом 8 у P меньше ложных срабатываний на мелких зубцах; при страйде 4 у сети больше якорей и больше дубликатов.
- **Отличие от R4.** R4 по покрытию якорями рекомендовал A. Эксперимент показал, что по основной метрике B лучше, а точность границ почти та же (DFL даёт субстрайдовую точность). Для статьи: «мелкий уровень со страйдом 8 достаточен; 4 не даёт выигрыша».
- **Размер.** small/medium не лучше nano по val: для 144 записей обучения ёмкости nano хватает (ср. Moskalenko: десятки тысяч параметров). Берём nano.

## 2. Подбор IoU для NMS (B nano, по val, без переобучения)

[e2_nms_sweep.py](../../experiments/scripts/e2_nms_sweep.py), чекпоинты `e2s1_B_nano` фолдов 0–1, пороги по классам подобраны на val:

| nms_iou | 0.05 | 0.1 | **0.2** | 0.3 | 0.45 | 0.55 | 0.65 (было) | 0.8 |
|---|---|---|---|---|---|---|---|---|
| val F1₆ | 99.20 | 99.18 | **99.11** | 98.91 | 98.79 | 98.72 | 98.60 | 98.30 |
| val σ₆, мс | 13.67 | 13.65 | **13.56** | 13.32 | 13.25 | 13.21 | 13.15 | 13.01 |

Волны одного класса в отведении не перекрываются, поэтому агрессивный NMS убирает дубли без потерь. **Выбран 0.2**: +0.5 п.п. F1 при росте σ на 0.4 мс (< δ_σ). При 0.05–0.1 F1 растёт ещё на ~0.1 п.п., но σ выходит за порог. На test (этап 2, `e2s2_ref`) переход 0.65 → 0.2 дал 98.27 → 98.78 %.

**По 10 прогонам (фолд × сид): ⟨F1⟩₆ = 98.55 ± 0.37 %, ⟨σ⟩₆ = 13.8 ± 0.34 мс.**

- **Сравнение с бенчмарками (R2, табл. 2.1).** Baseline без аугментаций уже на уровне лучших поотведенческих результатов: Moskalenko 98.51 % (обучен на 255 закрытых записях), Joung 98.84 % (I/II отв., внешний тест), ECG-CODE 98.10 %. По **точности границ** MyNet-1d лучше U-Net Moskalenko на всех точках, кроме совпадающего T_on: QRS 7.6/8.9 против 9.8 мс, P 13.7/12.4 против 14.1/15.7 мс. Протоколы различаются (данные обучения, разбиение, исключение крайних точек), поэтому сравнение предварительное. Итоговое — после E3/E4.
- **Средняя ошибка ≈ 0** для всех точек: систематического смещения границ нет.

### 4.2. Группы ритма (пулинг, seed 0)
| Группа | отведений | ⟨F1⟩₆ | Замечание |
|---|---|---|---|
| синус | 2096 | **99.23 %** | P: TP 15 985, FP 42, FN 539 |
| ФП/ТП | 180 | (QRS 99.7 %, T 94.5–95.4 %) | P в разметке нет; модель ставит **339 ложных P** (≈ 1.9 на отведение) на волнах f/F. ⟨F1⟩₆ = 64.9 % в `summary.md` — артефакт: F1 класса без разметки считается как 0 вместо «не определено» → задача **M5** |

### 4.3. Переобучение (train против test, лучший чекпоинт, те же пороги)
| Прогон | train F1₆ | test F1₆ | train σ₆ | test σ₆ |
|---|---|---|---|---|
| fold 0, seed 0 | 99.43 % | 98.71 % | 10.1 мс | 14.2 мс |
| fold 3, seed 0 | 99.51 % | 97.94 % | 8.9 мс | 13.3 мс |

- Разрыв ~0.7–1.6 п.п. F1 и ~4 мс σ. Val-лосс достигает минимума на 29–72-й эпохе, train-лосс падает до конца (1.9 → 1.4), лучшие эпохи по val-F1 — 25–141 (6 из 10 прогонов остановлены early stopping). **Модель переобучается; недообучения нет.** Нужна регуляризация данными — этап 3 (аугментации).
- Остаток подсказки на границе маски (D5) сохраняется: σ граничных точек QRS = 0.75–0.88 от внутренних. В метриках эти точки исключены.

### 4.4. Разброс baseline → пороги для абляции (A2)
SD по 10 прогонам: **SD(F1₆) = 0.37 п.п., SD(σ₆) = 0.34 мс**. По правилу R2 §3.3: **δ_F1 = max(0.2, 0.37) = 0.37 п.п., δ_σ = max(0.5, 0.34) = 0.5 мс** (для сравнения на тех же 10 прогонах). Разброс между фолдами (97.9–99.0 %) больше, чем между сидами (≤ 0.3 п.п. на фолде), поэтому абляцию сравнивать **попарно по фолду и сиду**.

## 5. Зафиксированный baseline
```yaml
model_size: nano
backbone_strides: B          # {8, 16, 32}
nms_iou: 0.2
max_lr: 0.01, batch_size: 32
epochs: 150, early_stopping_epochs: 40
ema_decay: 0.999, ema_tau: 200, bias_init: 1d
best_metric: F1_mean6, exclude_boundary_points: true
edge mask: train δ₁ ∈ [0, 12], δ₂ ∈ [0, 24]; eval 6 / 12
augmentations: нет
```
Время: ≈ 6.5 мин на прогон (early stopping), 10 прогонов ≈ 1 ч 50 мин.
