# Протокол абляции ЭКГ-аугментаций (A2)

**Зафиксирован:** 2026-10-07 (до запуска E3). Инструмент — [ablation.py](ablation.py) (конфиги, сводка, решения), прогон — `run_experiment.py`.
Основание: R2 §3.3 (метрика и пороги), R3 §3–§4 (кандидаты), E2 (baseline и разброс), A1 (реализация).

## 1. Что сравнивается
- **Эталонная модель** — baseline E2 ([baseline.yaml](../configs/baseline.yaml)): MyNet-1d nano, страйды B, nms_iou 0.2, до 150 эпох, early stopping 40. Меняются только аугментации (`augmentations.pipeline: ecg`, `augmentations.ecg.*`). Архитектура, лосс, оптимизатор, маска краёв, выбор чекпоинта и пороги оценки — как в baseline.
- **Кандидаты** — 16 аугментаций из A1 в 5 группах; вероятности из R3, остальные параметры — значения по умолчанию `ECGAugmentationSettings` ([docs/augmentations](../../docs/augmentations/README.md)):

| Группа | Аугментации (p) |
|---|---|
| N — шумы | N1 дрейф изолинии (0.5), N2 сетевая наводка (0.3), N3 мышечный шум (0.3), N4 белый шум (0.3), N5 шумы NSTDB (0.3), N6 ступенька изолинии (0.2), N7 случайная фильтрация (0.3) |
| T — время | T1 масштаб времени (0.5), T2 HRV-варп (0.5), T3 window warping (0.3) |
| A — амплитуда | A1 масштаб амплитуды (0.5), A2 масштаб волн (0.3), A3 инверсия (0.3) |
| M — маскирование | M1 обнуление отрезка (0.2) |
| X — склейка | X1 мозаика (0.2), X2 склейка по паузам (0.3) |

## 2. Метрики
- **Основная — ⟨F1⟩₆**: среднее F1 по 6 точкам, допуск ±150 мс, сопоставление один-к-одному, граничные точки исключены (R2 §3.2–3.3, D5). **Вторичная — ⟨σ⟩₆**: среднее SD ошибки положения, мс.
- **Дополнительно** (для анализа, не для решения): F1 и σ по классам P/QRS/T, число ложных P на отведение при ФП/ТП, ⟨|m|⟩₆.
- **Единица сравнения** — прогон (фолд, сид); метрики — test фолда, пороги уверенности подобраны на val фолда. Разности считаются **попарно** по одинаковым (фолд, сид): между фолдами разброс больше, чем между сидами (E2 §4.4). В решении используется средняя парная разность, рядом приводится её SD.
- **Ограничение.** Решения принимаются по test-фолдам CV: отдельного внешнего теста в LUDB нет. Чтобы не переподгонять набор под тест, число решений ограничено (группы → внутри групп), пороги консервативны, итоговые числа в E4 считаются с новыми сидами. Это оговаривается в статье.

## 3. Пороги и правило отбраковки
**Пороги** (R2 §3.3, разброс baseline по 10 прогонам E2): **δ_F1 = max(0.2 п.п., SD) = 0.37 п.п., δ_σ = max(0.5 мс, SD) = 0.5 мс.** `ablation.py` пересчитывает их из `experiments/baseline/summary.json`.

**Leave-out** (эталон — Full, кандидат — Full без X; Δ = кандидат − эталон). X (группа или аугментация):
- **отбрасывается**, если без неё F1 выше: ΔF1 ≥ +δ_F1, **или** F1 не хуже (ΔF1 ≥ −δ_F1/2), а σ меньше: Δσ ≤ −δ_σ;
- **полезна**, если без неё F1 ниже на ≥ δ_F1, или σ больше на ≥ δ_σ при ΔF1 ≤ δ_F1/2;
- иначе **нейтральна** — разница в пределах шума, X **сохраняется** (правило задачи A2: отбраковка только при ухудшении сверх δ).

**Add-one-in** (эталон — baseline, кандидат — baseline + X): вредна / полезна / нейтральна по тем же порогам (симметрично). Применяется только как уточнение (§4, шаг 4).

## 4. Схема (порядок прогонов)
Все прогоны — 5 фолдов × seed 0 (≈ 35 мин на конфиг на RTX 5060 Ti; baseline для сравнения уже есть с seed 0 и 1).

| Шаг | Конфиги | Команда генерации | Решение |
|---|---|---|---|
| 0 | `abl_full` — все 16 кандидатов | `ablation.py configs full` | Проверка: Full против baseline (add-one-in всего набора). Если Full **хуже** baseline на ≥ δ_F1 — схема leave-out неприменима, переход к add-one-in для всех групп (шаг 4) |
| 1 | `abl_full_minus_{N,T,A,M,X}` — 5 конфигов | `ablation.py configs groups` | Группа, которую правило §3 отбрасывает, удаляется целиком; для неё шаг 2 не нужен |
| 2 | `abl_full_minus_<ID>` для аугментаций сохранённых групп с ≥ 2 аугментациями | `ablation.py configs items --groups …` | Аугментация, которую правило §3 отбрасывает, удаляется |
| 3 | `abl_final` — Full без отброшенных | `ablation.py configs final --drop …` | Подтверждение: ⟨F1⟩₆ итогового набора ≥ Full − δ_F1/2. Иначе возвращаем по одной, начиная с аугментаций с наименьшим вкладом |
| 4 (по необходимости) | `abl_base_plus_<ID>` | `ablation.py configs add --ids …` | Если шаги 1–2 неоднозначны (две аугментации подменяют друг друга, например T1/T3 или X1/X2) или Full хуже baseline |

Бюджет: шаги 0–1 — 6 конфигов (≈ 3.5 ч); шаг 2 — до 16 конфигов (≈ 9 ч, меньше, если группы отброшены). Сиды на этапе абляции не повторяются: итоговый набор в E4 обучается на 5 фолдах × 2 новых сида.

## 5. Запуск и логирование
```bash
python experiments/ablation/ablation.py configs full
python run_experiment.py experiments/configs/abl_full.yaml
python experiments/ablation/ablation.py configs groups
for g in N T A M X; do python run_experiment.py experiments/configs/abl_full_minus_$g.yaml; done
python experiments/ablation/ablation.py summarize --ref abl_full
```
- Каждый прогон: конфиг, `environment.json` (git hash), `step.csv`, `metrics.json/md`, предсказания — как в M4. Строка в реестре `experiments/results.csv`.
- **`experiments/ablation/results.csv`** — все прогоны всех конфигов абляции, включая отброшенные: эксперимент, набор аугментаций, фолд, сид, ⟨F1⟩₆, ⟨σ⟩₆, ⟨|m|⟩₆, F1 и σ по P/QRS/T, ложные P при ФП.
- **`experiments/ablation/summary.md`** — средние по прогонам, парные разности к эталону ± SD, решение по правилу §3.
- Итог абляции (набор, таблица вкладов, анализ по классам) — `docs/results/E3_ablation.md`.
