Необходимо провести абляционное исследование для данных вихретоковых дефектограмм.

1. Немного изменился формат датасета. Причём датасет планируется опубликовать. Сам этот датасет находится по пути "E:\rails\public_dataset\dataset". Пока обращаемся к нему в локальной папке, но надо оставить возможность закачки его с huggingFace. Он будет лежать по адресу https://huggingface.co/datasets/Nasochec/ECRv1

    После загрузки датасета его необходимо преобразовать в формат, удобоворимый для нашей сети. Необходимо провести следующие преобразования: Подавление периодических помех, вычисление пороговых уровней. При вычислении пороговых уровней определяются битые каналы (заполненные нулями), после этого они заменяются на соседние. Используются вычисленные пороговые уровни для нормирования сигнала.
    
    Сами данные формируются как тензоры pytorch, куда попадают данные для обучения, причём в двух видах: с подавлением помех и бех подавления.
    
    Метки перекодируются в формат "YOLO" классы нумеруются начиная от 0 до 5, а координаты из формата (начало, конец) переводятся в формат (центр, ширина), причём нормированные по длине сигнала (диапазон [0,1])

Важно отметить: сейчас у меня нет времени на разрпуботку этого шага предобработки. У меня уже есть сформированный датасет по пути: H:\dataset\data_1d\dataset Файлик конфига: H:\dataset\data_1d\dataset\dataset.yaml

Поэтому пока пользуемся готовым, а после вычислительного эксперимента уже переработаем предобработку, пересоберём датасет, обучим модель и проверим совпадение.


2. Далее начинается эксперимент абляционный по аугментациям. 
    

    Сначала нужно обучить модель без аугментаций.
    Аугментации объединяются по группам:
    - геометрические преобразования:
        - Масштабирование сигнала (класс RandomResize). Растяжение или сжатие через линейную интерполяцию
        - обрезка сигнала (класс RandomCrop). Обрезка начала или конца сигнала, при условии, что сигнал длиннее заданной границы обрезки
        - случайное дополнение нулями (RandomPadding). Добавление нулей в начало или в конец сигнала
        - Инверсия сигнала по временной оси (класс RandomReverse)
    - Спектральные преобразования
        - Добавление шума в фазовый спектр сигнала (класс PhaseSpectrumNoise)
    - Аддитивный шум
        - Добавление обычного гауссовского шума (класс RandomJitter)
    - Амплитудные преобразования 
        - Инверсия полярности сигнала - умножение на -1 (класс RandomInvert)
        - Масштабирование амплитуд отдельных каналов (класс ChannelScaling)
    - Маскирование и окклюзия 
        - Маскирование по времени (класс TimeMasking)
        - Маскирование каналов (класс ChannelMasking)
    - Композитные преобразования 
        - mix-up
        - mosaic
        Эти аугментации вышиты в Датасет-загрузчик данных

    Аугментации добавляются по группам в том порядке, как перечислено выше. 

    Порядок самих аугментаций зашит в функции build_training_transforms в файле src\yolo_1d\utils\transforms\build_transforms.py и меняться не должен. (к примеру, паддинг добавляется в первой группе, но всё равно применяется последним, чтобы шумы не "испортили" добавленные нули)
