2. Далее начинается эксперимент абляционный по аугментациям. 
    
    Модель, используемая для обучения - базовая модель в этом репозитории, которая не подвергалась доработке для ЭКГ. То есть та, которая принимает на вход размер данных 49152. Припер запуска можно найти в `start_example.py`.

    Сначала нужно обучить модель без аугментаций.
    Аугментации объединяются по группам:
    - геометрические преобразования:
        - Масштабирование сигнала (класс RandomResize). Растяжение или сжатие через линейную интерполяцию
        - обрезка сигнала (класс RandomCrop). Обрезка начала или конца сигнала, при условии, что сигнал длиннее заданной границы обрезки
        - случайное дополнение нулями (RandomPadding). Добавление нулей в начало или в конец сигнала
        - Инверсия сигнала по временной оси (класс RandomReverse)
    - Спектральные преобразования
        - Добавление шума в фазовый спектр сигнала (класс PhaseSpectrumNoise)
    - Аддитивный шум
        - Добавление обычного гауссовского шума (класс RandomJitter)
    - Амплитудные преобразования 
        - Инверсия полярности сигнала - умножение на -1 (класс RandomInvert)
        - Масштабирование амплитуд отдельных каналов (класс ChannelScaling)
    - Маскирование и окклюзия 
        - Маскирование по времени (класс TimeMasking)
        - Маскирование каналов (класс ChannelMasking)
    - Композитные преобразования 
        - mix-up
        - mosaic
        Эти аугментации вшиты в Датасет-загрузчик данных
    - Синусоидальные помехи
        Нужно создать класс в transforms.py, который добавляет в сигнал синусоиду низкой периодичности. Параметры - границы частот low, high. Нужно как-то учесть, что на протяжении сигнала и частота и фаза синусоиды может немного меняться.
        По каналам синусоидная помеха добавляется как правило на соседние несколько каналов.
        Силу синусоиды на разных каналах было бы удобно моделировать так: мы берём гауссиан, генерируем параметры (m, sigma), номера каналов рассматриваем как координаты: -7/15, -6/15 ... 0, 1/15, ... 7/15 или что-то вроде того. Сила синусоиды получается как значение функции плотности норм. распределения в точке.
    - Прямоугольные шумы
        Класс SquareNoises. Из классу нужно убрать часть "подавление с ICA" теперь класс только добавляет помеху. Подавление с ICA становится самостоятельным классом
    

    Аугментации добавляются по группам в том порядке, как перечислено выше. 

    Порядок самих аугментаций зашит в функции build_training_transforms в файле src\yolo_1d\utils\transforms\build_transforms.py и меняться не должен. (к примеру, паддинг добавляется в первой группе, но всё равно применяется последним, чтобы шумы не "испортили" добавленные нули)

    Для всех аугментаций также нужно добавить RandomApply() с вероятностью 0.5, чтобы внести больше вариативности в обучение.
