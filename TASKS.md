**Принятые решения (обязательны для всех задач):**
- **Вход сети (2026-10-06):** полная запись ЭКГ 5000 отсчётов, дополненная нулями до **5120** — одинаково на обучении, валидации и тесте; одно окно на сигнал, без нарезки и скользящего окна. Неразмеченные края записи (до первой и после последней размеченной волны) после Z-score **обнуляются** при загрузке. Обоснование — R1 §4.2, R4 §2.4. **Уточнено в D5 (2026-10-07):** запас маски на train случайный (δ₁ ∈ [0, 12], δ₂ ∈ [0, 24] отсчётов), на val/test фиксированный (6 и 12); в метриках точки, соседние с границей маски, по умолчанию не учитываются.
- **Режим (2026-10-07, решение пользователя):** детекция **поотведенческая** (режим S): пример = одно отведение, вход сети 1 канал, разметка — собственная разметка отведения. Режим M (12 каналов с агрегированной разметкой) не реализуется; аугментации только для режима M (L1, L2 из R3) не нужны.
- **Дополнение SPEC (2026-10-10): режим MC — второй эксперимент.** Вход — **все 12 отведений записи** (12 × 5120), выход головы — **12 наборов предсказаний** (по одному на отведение, выходные слои голов шире в 12 раз), каждый предсказывает разметку **своего** отведения. **Лосс исходный**, считается для каждого отведения отдельно и суммируется. Метрики — **как в режиме S** (поотведенческие, те же 6 точек, допуск, пулинг), поэтому S и MC сравниваются напрямую. Сначала два конфига: без аугментаций и со всеми аугментациями (включая многоканальные); абляция по группам — позже, по решению пользователя. Этап 3.5.

- [x] **R3** `[RESEARCH]` **Аугментации для ЭКГ.**
  Обзор аугментаций, применяемых в задачах делинеации и классификации ЭКГ (например, Rahman et al., Lee et al., «ECG augmentation survey», работы на PTB-XL).   Для каждой: физический смысл, диапазоны параметров из литературы, сохраняет ли разметку (как корректировать границы при time warping), применимость к многоканальному сигналу.
  Отдельно оценить, какие из существующих в репозитории трансформаций некорректны для ЭКГ (например, `RandomReverse`, `RandomInvert`).

  - Литература: больше всего дают временная геометрия (resized crop / window warping — SemiSegECG, Iwana) и синтетика из размеченных сегментов (+0.62 % F1, Jiménez-Pérez 2024). Шумы, заданные через SNR, дают умеренный прирост. Флип по времени вредит (SemiSegECG, Rahman, Iwana).

  - **Многоканальные аугментации:** физика 12 отведений (Эйнтховен/Гольдбергер: III = II − I, aVR = −(I + II)/2, …, грудные — от отдельных электродов).
