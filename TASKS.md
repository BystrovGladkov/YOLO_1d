- [x] **R3** `[RESEARCH]` **Аугментации для ЭКГ.**
  Обзор аугментаций, применяемых в задачах делинеации и классификации ЭКГ (например, Rahman et al., Lee et al., «ECG augmentation survey», работы на PTB-XL). Помимо указанных в SPEC (baseline wander 0.1–0.5 Гц, сетевая наводка 50/60 Гц, миографический шум, time warping, lead dropout/shuffling) рассмотреть: шум электродов (electrode motion, NSTDB), масштабирование амплитуды по отведениям, случайный сдвиг/кроп окна, смещение изолинии (DC), random lowpass/highpass фильтрацию, смешивание с реальными шумами MIT-BIH NSTDB, mixup/mosaic (уже есть в коде), cutout/time masking.
  Для каждой: физический смысл, диапазоны параметров из литературы, сохраняет ли разметку (как корректировать границы при time warping), применимость к многоканальному сигналу.
  Отдельно оценить, какие из существующих в репозитории трансформаций некорректны для ЭКГ (например, `RandomReverse`, `RandomInvert`).
  Результат: `docs/research/R3_augmentations.md` + финальный список аугментаций-кандидатов для абляции.
  **Итог:** [docs/research/R3_augmentations.md](docs/research/R3_augmentations.md).
  - Литература: больше всего дают временная геометрия (resized crop / window warping — SemiSegECG, Iwana) и синтетика из размеченных сегментов (+0.62 % F1, Jiménez-Pérez 2024). Шумы, заданные через SNR, дают умеренный прирост. Флип по времени вредит (SemiSegECG, Rahman, Iwana).
  - Разбор кода: исключить `RandomReverse`, `PhaseSpectrumNoise`, `SquareNoises`, Mix-up. `RandomJitter` σ = 0.6 слишком силён (SNR ≈ 4 дБ) → SNR 20–35 дБ. `RandomInvert` — только для режима S. `MarkScaling` (амплитуда одной волны) — ценный кандидат. Валидационный `Resize` заменить паддингом.
  - 17 кандидатов в 6 группах (N — шумы, T — время, A — амплитуда, L — отведения, M — маски, X — композиция) с диапазонами параметров. Новый ЭКГ-специфичный T2 «HRV-варп»: растягивается диастола (TP), волны почти не меняются, боксы пересчитываются.
  - Абляция: leave-one-group-out → leave-one-out внутри сохранённых групп. Плюс noise stress test на NSTDB (SNR 24/12/6 дБ) для статьи.
  - ⚠️ В `src/yolo_1d/utils/transforms/transforms.py` (строки 378–380) закоммичен посторонний текст (имя, e-mail, строка, похожая на пароль) → модуль не импортируется. Блокирует A1.

- [x] **R4** `[RESEARCH]` **Адаптация архитектуры под короткий сигнал.**
  Проанализировать текущую архитектуру (`src/yolo_1d/nets/nn.py`: 9 свёрток с шагом 2, выходные страйды ≈32/128/256 при входе 49152) применительно к LUDB: вход 5000 отсчётов, длительности волн ~40–120 мс (20–60 отсчётов) для P/QRS и до ~200 мс для T.
  Определить: длину входа (кандидаты 5120 = 5·2¹⁰ с паддингом или 4096 с кропом), нужные страйды голов (чтобы на один объект приходилось несколько якорей), рецептивное поле, количество и расположение даунсэмплингов, число входных каналов (12 вместо 30).
  Посмотреть, как это делают 1D-детекторы/сегментаторы ЭКГ (U-Net, 1D-YOLO, ECG-детекторы на основе anchor-free подходов).
  Результат: `docs/research/R4_architecture.md` с 2–3 вариантами конфигурации и рекомендацией.
  **Итог:** [docs/research/R4_architecture.md](docs/research/R4_architecture.md), скрипты [r4_anchor_coverage.py](docs/research/scripts/r4_anchor_coverage.py), [r4_variants.py](docs/research/scripts/r4_variants.py).
  - Текущие страйды {32, 128, 256} непригодны: при s = 32 на P/QRS в среднем 1.5 якоря (TAL берёт только якоря внутри GT), уровни 128/256 не содержат якорей внутри волн. DFL (16 бинов) ограничивает регрессию 15·s на сторону.
  - Требования: мелкий уровень s = 4 (12 якорей на P/QRS), уровень s ≥ 16 для длинных T, контекст ≥ 1 цикла (≥ 1.5 с).
  - **Рекомендация — вариант A {4, 16, 32}:** у 3-й…5-й свёрток `p1` шаг 2 → 1, FPN без изменений. 1.1 M параметров (nano), 546 M MACs @5120, свёрточный РП после FPN 1.6–2.4 с. Альтернатива для E2 — вариант C {4, 8, 16} (нужна параметризация FPN).
  - Вход: **единый 5120 на обучении и валидации** (5000 + паддинг; без паддинга FPN падает), неразмеченные края обнулены. Фиксированное окно внутри зоны отклонено: при L = 2048/3072 в оценку попадает лишь 52/79 % волн (R4 §2.4). Каналы 1 (S) / 12 (M).
  - Попутно найдено: `initialize_biases` использует 2D-формулу (−11.9 вместо ≈ −4.4), `fuse_conv` создаёт `Conv2d`.
