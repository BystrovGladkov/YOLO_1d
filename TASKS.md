**Принятые решения (обязательны для всех задач):**
- **Вход сети (2026-10-06):** полная запись ЭКГ 5000 отсчётов, дополненная нулями до **5120** — одинаково на обучении, валидации и тесте; одно окно на сигнал, без нарезки и скользящего окна. - [x] **R3** `[RESEARCH]` **Аугментации для ЭКГ.**
  Обзор аугментаций, применяемых в задачах делинеации и классификации ЭКГ (например, Rahman et al., Lee et al., «ECG augmentation survey», работы на PTB-XL). Помимо указанных в SPEC (baseline wander 0.1–0.5 Гц, сетевая наводка 50/60 Гц, миографический шум, time warping, lead dropout/shuffling) рассмотреть: шум электродов (electrode motion, NSTDB), масштабирование амплитуды по отведениям, случайный сдвиг/кроп окна, смещение изолинии (DC), random lowpass/highpass фильтрацию, смешивание с реальными шумами MIT-BIH NSTDB, mixup/mosaic (уже есть в коде), cutout/time masking.
  Для каждой: физический смысл, диапазоны параметров из литературы, сохраняет ли разметку (как корректировать границы при time warping), применимость к многоканальному сигналу.
  Отдельно оценить, какие из существующих в репозитории трансформаций некорректны для ЭКГ (например, `RandomReverse`, `RandomInvert`).
  Результат: `docs/research/R3_augmentations.md` + финальный список аугментаций-кандидатов для абляции.
  **Итог:** [docs/research/R3_augmentations.md](docs/research/R3_augmentations.md).
  - Литература: больше всего дают временная геометрия (resized crop / window warping — SemiSegECG, Iwana) и синтетика из размеченных сегментов (+0.62 % F1, Jiménez-Pérez 2024). Шумы, заданные через SNR, дают умеренный прирост. Флип по времени вредит (SemiSegECG, Rahman, Iwana).
  - Разбор кода: исключить `RandomReverse`, `PhaseSpectrumNoise`, `SquareNoises`, Mix-up. `RandomJitter` σ = 0.6 слишком силён (SNR ≈ 4 дБ) → SNR 20–35 дБ. `RandomInvert` — только для режима S. `MarkScaling` (амплитуда одной волны) — ценный кандидат. Валидационный `Resize` заменить паддингом.
  - 17 кандидатов в 6 группах (N — шумы, T — время, A — амплитуда, L — отведения, M — маски, X — композиция) с диапазонами параметров. Новый ЭКГ-специфичный T2 «HRV-варп»: растягивается диастола (TP), волны почти не меняются, боксы пересчитываются.
  - Абляция: leave-one-group-out → leave-one-out внутри сохранённых групп. Плюс noise stress test на NSTDB (SNR 24/12/6 дБ) для статьи.
