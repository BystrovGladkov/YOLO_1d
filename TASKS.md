Структура `{train,val,test}/{data,labels}`, сигналы `passage{K}_{side}_{NNNN}.npy`, `int16`, форма `(15, length)`, длина обычно 50 000 (минимум 4 409). Разметка — строки `type begin end` в отсчётах; классы `1, 2, 3, 4, 5, 12` → перекодировать в `0…5` (flashbutt, aluminothermic, rail end, axle counter, crossing, manual arc). Объём: 2099 / 560 / 294 файлов.
- **Старый датасет (эталон для сверки):** `H:\dataset\data_1d\dataset`, конфиг `H:\dataset\data_1d\dataset\dataset.yaml`. Тензоры `.pt`, `float16`, **30 каналов**: `[0:15]` — сигнал без подавления помех, `[15:30]` — с подавлением, оба нормированы на пороговый уровень. Разметка — YOLO `cls x_center width`, нормированная на длину сигнала.
- **Эталонный код предобработки:** [EC_preprocess/preprare.py](EC_preprocess/preprare.py) (`prepare_signal`: ICA-фильтрация → Фурье-выравнивание `fftine_fast(convert_freq(0.03, L))` → `Get_Signal_Thresholds` → `New_Channel_Substitution`), [EC_preprocess/dataset_converter.py](EC_preprocess/dataset_converter.py) (сборка 30-канального тензора и разметки), [EC_preprocess/kuzmin_levels.py](EC_preprocess/kuzmin_levels.py) (пороги и замена битых каналов).
- **ICA_filtration** берётся из [src/yolo_1d/utils/transforms/square_noises.py](src/yolo_1d/utils/transforms/square_noises.py) с параметрами, как в `SquareNoises`: `median=True, EMA=True, method='hyvarinen'`, остальные — значения по умолчанию.
- **Нормирующий уровень σ (решение пользователя, 2026-10-16):** в `prepare_signal` добавлено `signal.sigma = min(|thplus|, |thmins|) / 3` по `_Threshold1` каждого канала. Пороги битых каналов к этому моменту уже заменены на пороги соседнего канала (`New_Channel_Substitution` обновляет `Threshold1`), так что σ битого канала = σ его замены. **Опечатку исправить при переносе:** в исходной строке `np.array(<генератор>) / 3` → `TypeError`, нужен список `np.array([...]) / 3`.
- **Известные несостыковки в `EC_preprocess`** (решаются в D1): `get_1d_data` вызывает `prepare_signal(raw_data, furier=..., SW=True)`, а текущая `prepare_signal` этих аргументов не принимает — вызывать без них. В `prepare_labels` есть принудительная рамка 200 мм для коротких классов — в ECRv1 границы уже даны, рамку не применяем.
- **Seed:** разбиение датасета одно и фиксировано (train/val/test ECRv1) и не меняется. Под «seed» везде понимается зерно генератора случайных чисел для **начальной инициализации весов** (и, как следствие, порядка батчей и случайности аугментаций) — `util.setup_seed(seed)`.
- **Модель:** базовая вихретоковая модель репозитория, вход 49 152 (`regular_length=50000`, `input_length=49152`, `validation_resize=True`, `pipeline="eddy"`). Пример запуска — [start_example.py](start_example.py).
- **SquareNoises вынесена из абляции (решение пользователя, 2026-10-16):** кумулятивная абляция — **A0…A6** (без прямоугольных шумов, `square_noises=0` во всех конфигах). Вклад `SquareNoises` оценивается **отдельным сравнением после абляции** (E5): итоговый набор аугментаций из абляции против того же набора + `SquareNoises`. Генератор `new_smooth_noise` воспроизводит реальную помеху (подтверждено пользователем) — его параметры не меняем.
- **Порядок аугментаций** зафиксирован в `build_training_transforms` ([src/yolo_1d/utils/transforms/build_transforms.py](src/yolo_1d/utils/transforms/build_transforms.py)) и **не меняется**: включение/выключение групп — только через параметры `AugmentationSettings`.

- [x] **R1** `[RESEARCH]` **Протокол абляционных исследований аугментаций для детекции во временных рядах.**
  **Итог (2026-10-16), [EC_R1_ablation_protocol.md](docs/research/EC_R1_ablation_protocol.md):** основная схема — кумулятивная A0→A6 (SPEC; SquareNoises вынесена в E5); для групп с Δ ≤ 0 или в пределах шума — дополнительно A6 − группа. **3 seed инициализации** на конфиг (одинаковый набор `0,1,2` → парное сравнение), +2 seed для соседних пар с |Δ| < 2·SD. Основная метрика — **макро mAP@0.5:0.95** на test, вторичные — mAP@0.5, поклассовые AP, P/R. Разброс — mean ± SD по seed + 95 % парный bootstrap по 294 тестовым сигналам; Holm для 6 шагов. Требования к D6: параметр `--seed`, сохранение `per_sample` test, `setup_seed` до создания модели.
  Найти статьи по абляции аугментаций для 1D-сигналов / временных рядов (обзоры Iwana & Uchida 2021, Wen et al. «Time Series Data Augmentation for Deep Learning», работы по аугментациям в NDT / вихретоковом контроле и по YOLO-подобной детекции в 1D).
  Выяснить:
  - кумулятивная (добавление групп) или leave-one-out схема — что принято и как интерпретировать результаты кумулятивной схемы (зависимость от порядка добавления);
  - сколько запусков с разными seed инициализации весов (разбиение фиксировано) нужно для устойчивого вывода, как оценивать разброс и значимость (mean ± std по seed, bootstrap по тестовым сигналам);
  - какие метрики детекции отчитывать (mAP@0.5, mAP@0.5:0.95, поклассовые AP, precision/recall), особенно при сильном дисбалансе классов (flashbutt + aluminothermic ≈ 84 % объектов).
  Результат: `docs/research/EC_R1_ablation_protocol.md` с рекомендацией по числу seed, метрикам и формату итоговой таблицы.

- [x] **R2** `[RESEARCH]` **Подавление помех в вихретоковых дефектограммах и аугментация «прямоугольными шумами».**
  **Итог (2026-10-16), [EC_R2_noise_suppression.md](docs/research/EC_R2_noise_suppression.md):** шаги предобработки сопоставлены с публикациями (пороги — Кузьмин 2017/2018/2021; спектральное вычитание — Быстров, Гладков, Кузьмин 2024; SW-характеристика — 2025; FastICA + негэнтропия Hyvärinen 1998); обоснование двух версий входа — Jung 2000, Del Pup 2024; аугментации — Venton & Aston 2021, Tobin 2017; черновик «Методов» (EN). Замеры: при применении SquareNoises помеха покрывает ≈53 % сигнала, амплитуда ≈9 ед., 0.2–0.8 с CPU на пример. **Риски → задачи:** масштаб помехи относительно новой нормировки (D4), синфазность помехи — подтверждено пользователем (помеха соответствует реальной), вклад SquareNoises может не проявиться на чистом test → оценка на test + SquareNoises (E5).
  Кратко собрать литературу по ICA/BSS-фильтрации многоканальных вихретоковых сигналов и по аугментации синтетическими помехами (domain randomization, noise injection с последующим подавлением). Цель — обоснование для статьи, почему в тензор кладутся обе версии сигнала (с подавлением и без) и почему группа SquareNoises добавляется последней.
  Результат: `docs/research/EC_R2_noise_suppression.md` (список источников + 1–2 абзаца для раздела «Методы»).

## Этап 4. Отдельное сравнение: прямоугольные шумы

- [~] **E5** `[EXPERIMENT]` **Итоговый набор vs итоговый набор + SquareNoises.**

## Этап 5. Абляция входа: сырой / очищенный / оба (решение пользователя, 2026-10-16)
